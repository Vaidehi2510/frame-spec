# v0.1.1 Self Frame Example

This example applies the minimal `v0.1.1` spec to the Frame spec itself.

It is intentionally self-referential:

- the spec defines the minimum shape of a Frame
- this example uses that minimum shape to describe how the spec should be understood and used

Unlike the richer [../self-frame/README.md](../self-frame/README.md) example, this version stays inside the current adopt-now boundary:

- one Markdown file
- YAML frontmatter
- no package manifest
- no formal inheritance
- no extra infrastructure

Use this example when you want to see what a self-describing Frame looks like under the minimal spec.
